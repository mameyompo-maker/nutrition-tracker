# 食事栄養トラッカー

食事の写真を撮ると、AIがその写真から栄養素を推定し、あなたの年齢・性別・体重などから
計算した「1日に必要な栄養量」と比較して、残り必要な栄養素や食べ方のアドバイスを表示する
アプリです。

**公開URL: https://mameyompo-maker.github.io/nutrition-tracker/**

- サーバーは不要です。静的なHTML/CSS/JavaScriptだけで動きます(GitHub Pagesで公開)。
- データはすべてこの端末のブラウザ内(localStorage)に保存され、開発者には送信されません。
- 写真解析のときだけ、写真とAPIキーが**あなた自身が選んだAIサービス**に直接送信されます。
- 宅配弁当や社食アプリの「成分表(目安)」のような、栄養成分がすでに印刷・表示されている
  写真(パッケージやアプリ画面のスクリーンショットなど)を撮った場合は、AIが写真から
  その数値をそのまま読み取って使います(「成分表示を読み取りました」と表示されます)。
  数値の記載がない場合は、写真から見た目で推定します。

## 画面の設計

Appleのヒューマンインターフェイスの考え方に寄せてあります。

- ほぼ無彩色の面に、アクセント色(このアプリの緑)を一点だけ置く
- 余白を広く取り、罫線と装飾は最小限にする。見出しは大きく太く、本文は小さく静かに
- 角丸は 10 / 12 / 16 / 22px。`corner-shape: squircle` に対応したブラウザでは本物のスクワークルになる
- フォントは SF Pro(なければ Inter / Helvetica Neue / ヒラギノ角ゴ)。
  大きな数値だけ New York(セリフ)で組む
- ライト/ダークの両方に対応し、端末の設定に従う
- Webフォントは読み込まない(表示が速く、外部への通信も減る)

初回起動は3段階(ようこそ → からだのこと → AIにつなぐ)に分けてあり、
AIの設定は飛ばしても使い始められます。

## 写真解析のしくみ (BYOK: Bring Your Own Key)

このアプリは開発者のAPIキーを持ちません。利用者が自分のAIサービスのAPIキーを設定画面に
登録し、ブラウザからそのAIを直接呼び出します。したがって

- 開発者側に運用コストが発生しない(誰が何人使っても無料)
- 利用者のキー・写真・記録が開発者のサーバーを経由しない

という形になっています。

### 対応しているAIサービス

| サービス | 費用 | 備考 |
|---|---|---|
| **Google Gemini** (既定) | **無料枠あり** | Google AI Studio でクレジットカード不要のキーを発行できる。**これが無料で使う場合の推奨** |
| Claude (Anthropic) | 有料 | 事前のクレジット購入が必要 |
| OpenAI (ChatGPT) | 有料 | 事前のクレジット購入が必要 |
| その他 (OpenAI互換) | サービス次第 | OpenRouter・Groq・ローカルLLMなど。ベースURLとモデル名を自由に入力できる |
| **手動方式** (APIキー不要) | **完全無料** | 指示文をコピーして手持ちのAIチャットに貼り、返ってきたJSONをアプリに貼り戻す |

モデル名の入力欄は自由入力です。各社のモデルは入れ替わりが速いため、候補が古くなっても
利用者が最新のモデル名を直接入力すればそのまま動きます。

## 無料で使う手順 (Google Gemini)

1. https://aistudio.google.com/apikey にGoogleアカウントでアクセス
2. 「Create API key」でキーを発行(**クレジットカード不要・無料**)
3. アプリの初回設定画面、または「設定」タブで
   - 使うAIサービス: **Google Gemini**
   - APIキー: 発行したキー(`AIza...`)
   - モデル: `gemini-3.5-flash-lite`(既定。無料枠では混雑に強く安定)
4. 「接続テスト」ボタンで疎通を確認してから保存

APIキーの取り方が分からない場合は、APIキー入力欄の右にある
**「取得のしかた」**を押してください。アプリの中に手順書が開きます
(サービスごとに内容が変わります)。設定タブからも開けます。

### 無料枠の注意点

- 無料枠には1日あたり・1分あたりのリクエスト数の上限があります(Flash系でおおむね
  1日1,500回程度)。個人が食事を記録する用途なら十分ですが、正確な上限は
  https://aistudio.google.com/rate-limit で確認してください。
- 無料枠では、送信した内容がGoogleのサービス改善に利用される場合があります。
  食事の写真を送ることになるため、気になる場合は有料枠に切り替えるか、
  APIキーを使わない「手動方式」をお使いください。
- **課金を有効にすると、そのプロジェクトの無料枠は無くなります**(以後すべて従量課金)。
  無料のまま使いたい場合は課金を有効にしないでください。
- 混雑時は503エラーが出ることがあります。アプリ側で自動的に数回投げ直しますが、
  それでも失敗する場合は少し時間をおいてください。

## APIキーを使わない方法(完全無料)

「記録」タブで写真を選び、「APIキーを使わない方法」を開くと、

1. 解析用の指示文をコピー
2. その指示文と写真を、手持ちのAIチャット(ChatGPT・Claude・Gemini など。無料プランで可)に貼って送信
3. 返ってきたJSONをアプリに貼り戻す

という手順で、APIキーなしで同じ解析結果が得られます。
また、解析結果の数値はすべて手で修正できるので、AIを使わず自分で入力することもできます。

## APIキーの扱いについて

APIキーはこの端末のブラウザ内(localStorage)にのみ保存されます。ただし
「ブラウザから直接APIキーを使う」方式は、そのブラウザ環境にアクセスできる人には
キーが見える形になります。共有PCなどでは使用後にキーを削除してください。
キーが漏れた場合は、発行元のコンソールからそのキーを失効させてください。

## ローカルで動かす

```bash
cd nutrition_tracker
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。
`index.html` を直接ダブルクリックしても動きますが、サービスワーカー(オフライン対応)を
有効にするには簡易サーバー経由が必要です。

## スマホのホーム画面に追加する

公開URLをスマホのブラウザで開き、共有メニューから「ホーム画面に追加」を選ぶと、
PWAとしてアプリのように使えます(オフラインでも画面は開きます。写真解析には通信が必要)。

## ファイル構成

- `index.html` — アプリ本体(画面構造)
- `style.css` — デザイン
- `nutrition.js` — 1日の必要栄養量の計算ロジック
- `storage.js` — 記録の保存(localStorage)
- `api.js` — 各AIサービスへの写真解析リクエスト(プロバイダ定義もここ)
- `app.js` — 画面の描画とイベント処理
- `icons.js` — SVGアイコン(絵文字は使わず線画で統一)
- `manifest.json` / `sw.js` / `icon-*.png` — PWA(ホーム画面追加・オフライン対応)用

## 注意事項

本アプリが表示する1日の必要栄養量やAIによる栄養推定値は、一般的な目安・参考情報であり、
医学的なアドバイスではありません。妊娠・授乳中の方、成長期のお子様、持病のある方などは、
医師や管理栄養士にご相談のうえご利用ください。18歳以上の方を対象としています。
