# 食事栄養トラッカー

食事の写真を撮ると、AIがその写真から栄養素を推定し、あなたの年齢・性別・体重などから
計算した「1日に必要な栄養量」と比較して、残り必要な栄養素や食べ方のアドバイスを表示する
アプリです。

**公開URL: https://mameyompo-maker.github.io/nutrition-tracker/**

- サーバーは不要です。静的なHTML/CSS/JavaScriptだけで動きます(GitHub Pagesで公開)。
- データはすべてこの端末のブラウザ内(localStorage)に保存され、開発者には送信されません。
- 写真解析のときだけ、写真とAPIキーが**あなた自身が選んだAIサービス**に直接送信されます。
- 宅配弁当や社食アプリの「成分表(目安)」のような、栄養成分がすでに印刷・表示されている
  写真(パッケージやアプリ画面のスクリーンショットなど)を撮った場合は、AIが写真から
  その数値をそのまま読み取って使います(「成分表示を読み取りました」と表示されます)。
  数値の記載がない場合は、写真から見た目で推定します。

## できること

| 画面 | 内容 |
|---|---|
| **ホーム** | その日のエネルギーをリングで、たんぱく質・脂質・炭水化物を色分けしたバーで表示。この1週間のミニグラフと連続記録日数。食事は朝食・昼食・間食・夕食に分けて小計つきで並ぶ |
| **記録** | 写真を撮る/選ぶ/貼り付けて解析。写真なしの手入力、よく食べるものの1タップ登録も |
| **トレンド** | 週/月で切り替え。エネルギーの棒グラフ、エネルギー産生栄養素バランス(目標量の帯つき)、体重の折れ線、栄養素16項目の平均充足率 |
| **履歴** | 日ごとの一覧。料理名での検索は日付をまたいで探せる |
| **設定** | プロフィール、AIの接続、よく食べるものの整理、データの書き出し/読み込み |

記録はどこからでもタップして開き、**名前・区分・時刻・メモ・全栄養素を後から直せます**。
削除は取り消せます(トーストの「元に戻す」)。そこから**「共有」**を選べば、
写真と栄養を1枚のカードにして X・Instagram・LINE などへ渡せます(下記)。

## 栄養の基準値

目標値は、厚生労働省「日本人の食事摂取基準(2025年版)」策定検討会報告書の表から、
18歳以上の年齢区分(18〜29 / 30〜49 / 50〜64 / 65〜74 / 75以上)ごとに転記しています
([出典](https://www.mhlw.go.jp/stf/newpage_44138.html))。

- エネルギー = **基礎代謝基準値(kcal/kg体重/日) × 体重 × 身体活動レベル**
  (報告書 表3・表5)。参照体重を入れると、報告書の「推定エネルギー必要量」の表と
  男女×5区分×3レベルの**28通りすべてが一致**することを確認済み。
- たんぱく質・カルシウム・鉄・亜鉛・マグネシウム・ビタミンA/C/B1/B2/B6・葉酸は**推奨量**、
  ビタミンD/E/B12は**目安量**、食物繊維・食塩相当量・カリウムは**目標量**。
- 鉄は月経の有無で推奨量が変わるため、18〜64歳の女性にのみ月経の有無をお尋ねします。
- P/F/Cは目標量(たんぱく質13〜20% / 脂質20〜30% / 炭水化物50〜65%エネルギー)の
  範囲に収まるよう配分します。増量・減量による調整だけは食事摂取基準の範囲外の目安です。

設定タブの「1日の目標の求め方」から、計算式と栄養素ごとの根拠(推奨量・目安量・目標量の別)
をその場で確認できます。トレンド画面のエネルギー産生栄養素バランスでは、**目標量の範囲を
帯で示し、実績がその中に入っているか**を一目で確かめられます。

## 量の判定 — 撮影情報を使う

写真だけでは「大盛り」と「カメラを近づけただけ」が区別できません。そこでこのアプリは、
写真に埋め込まれた撮影情報(EXIF)を読み取り、**写る範囲の実寸まで計算してAIに渡します**。

- 35mm換算焦点距離から**水平画角**を求める
- 被写体距離が記録されていれば、相似三角形から
  **「画像の横幅いっぱいが実際の何cmに相当するか」**を計算する
  (例: 35mm換算24mm・距離0.33m → 横 約49.5cm)
- カメラ機種・レンズ・デジタルズーム倍率・元の画素数も併せて渡す
- 撮影情報が無い画像(スクリーンショットなど)はその旨をAIに伝え、
  写り込んだ既知の大きさのもの(箸・茶碗・ペットボトルなど)だけを手がかりにさせる

**位置情報(GPS)は読み取らず、送信もしません。** 記録画面のバッジをタップすると、
AIへ実際に送る撮影情報をそのまま確認できます。

解析結果には「推定した合計重量」「判断のしかた」「基準にしたもの」が表示され、
AIが何を根拠に量を決めたかが分かります。この情報は記録にも残ります。

## 画面の設計

Appleのヒューマンインターフェイスの考え方に寄せてあります。

- ほぼ無彩色の面。アクセント色(このアプリの緑)は操作と達成を示すときだけ
- **色を増やすのはデータだけ。** たんぱく質(青)・脂質(黄)・炭水化物(ティール)に
  Appleのシステムカラーを1色ずつ割り当て、グラフとバーにのみ使う。画面の飾りには使わない
- 余白を広く取り、罫線と装飾は最小限にする。見出しは大きく太く、本文は小さく静かに
- 角丸は 10 / 12 / 16 / 22px。`corner-shape: squircle` に対応したブラウザでは本物のスクワークルになる
- フォントは SF Pro(なければ Inter / Helvetica Neue / ヒラギノ角ゴ)。
  大きな数値だけ New York(セリフ)で組む
- ライト/ダークの両方に対応し、端末の設定に従う
- Webフォントもグラフのライブラリも読み込まない(表示が速く、外部への通信も無い)

初回起動は3段階(ようこそ → からだのこと → AIにつなぐ)に分けてあります。
最後の段階では、**「接続テスト」でAIにつながることを確認するまで先に進めません。**
キーやモデル名を書き換えると確認は取り消され、もう一度テストが必要になります。

## ホーム画面に追加したときの挙動

ホーム画面に追加すると、ブラウザの枠のない単独のアプリとして起動します。
入れたアプリと同じ感触になるよう、次のようにしてあります。

- 引っ張って更新・行き過ぎたときの跳ね返り・長押しのメニュー・文字の選択・
  ダブルタップの拡大を止める(入力欄と読み物だけは選択できるまま残す)
- スクロールすると、上端に小さなタイトルバーが半透明で現れる
- タブを切り替えると中身がふわっと入れ替わる
- シートは下から出て、つまんで下に払うと閉じる
- 節目の操作で短く振動する(対応端末のみ。iOSでは無視されます)
- アイコンを長押しすると「食事を記録」「体重を記録」「トレンドを見る」に直接入れる

## 写真解析のしくみ (BYOK: Bring Your Own Key)

このアプリは開発者のAPIキーを持ちません。利用者が自分のAIサービスのAPIキーを設定画面に
登録し、ブラウザからそのAIを直接呼び出します。したがって

- 開発者側に運用コストが発生しない(誰が何人使っても無料)
- 利用者のキー・写真・記録が開発者のサーバーを経由しない

という形になっています。

### 対応しているAIサービス

| サービス | 費用 | 備考 |
|---|---|---|
| **Google Gemini** (既定) | **無料枠あり** | Google AI Studio でクレジットカード不要のキーを発行できる。**これが無料で使う場合の推奨** |
| Claude (Anthropic) | 有料 | 事前のクレジット購入が必要 |
| OpenAI (ChatGPT) | 有料 | 事前のクレジット購入が必要 |
| その他 (OpenAI互換) | サービス次第 | OpenRouter・Groq・ローカルLLMなど。ベースURLとモデル名を自由に入力できる |
| **手動方式** (APIキー不要) | **完全無料** | 指示文をコピーして手持ちのAIチャットに貼り、返ってきたJSONをアプリに貼り戻す |

モデル名の入力欄は自由入力です。各社のモデルは入れ替わりが速いため、候補が古くなっても
利用者が最新のモデル名を直接入力すればそのまま動きます。

## 無料で使う手順 (Google Gemini)

1. https://aistudio.google.com/apikey にGoogleアカウントでアクセス
2. 「Create API key」でキーを発行(**クレジットカード不要・無料**)
3. アプリの初回設定画面、または「設定」タブで
   - 使うAIサービス: **Google Gemini**
   - APIキー: 発行したキー(`AIza...`)
   - モデル: `gemini-3.5-flash-lite`(既定。無料枠では混雑に強く安定)
4. 「接続テスト」ボタンで疎通を確認してから保存

APIキーの取り方が分からない場合は、APIキー入力欄の右にある
**「取得のしかた」**を押してください。アプリの中に手順書が開きます
(サービスごとに内容が変わります)。設定タブからも開けます。

### 無料枠の注意点

- 無料枠には1日あたり・1分あたりのリクエスト数の上限があります(Flash系でおおむね
  1日1,500回程度)。個人が食事を記録する用途なら十分ですが、正確な上限は
  https://aistudio.google.com/rate-limit で確認してください。
- 無料枠では、送信した内容がGoogleのサービス改善に利用される場合があります。
  食事の写真を送ることになるため、気になる場合は有料枠に切り替えるか、
  APIキーを使わない「手動方式」をお使いください。
- **課金を有効にすると、そのプロジェクトの無料枠は無くなります**(以後すべて従量課金)。
  無料のまま使いたい場合は課金を有効にしないでください。
- 混雑時は503エラーが出ることがあります。アプリ側で自動的に数回投げ直しますが、
  それでも失敗する場合は少し時間をおいてください。

## APIキーを使わない方法(完全無料)

「記録」タブで写真を選び、「APIキーを使わない方法」を開くと、

1. 解析用の指示文をコピー
2. その指示文と写真を、手持ちのAIチャット(ChatGPT・Claude・Gemini など。無料プランで可)に貼って送信
3. 返ってきたJSONをアプリに貼り戻す

という手順で、APIキーなしで同じ解析結果が得られます。指示文には撮影情報も含まれるため、
手動方式でも量の判定には同じ手がかりが使われます。
また、解析結果の数値はすべて手で修正できるので、AIを使わず自分で入力することもできます。
「写真なしで記録」を使えば、名前と分かる数値だけでも記録できます。

ただし**初回設定では接続テストの成功が必須**のため、この方法だけで使い始めることはできません。
一度APIキーを登録して始めたあと、日々の記録でこの方法を使う、という形になります。

## 人に見せる(共有)

記録を開いて「この食事を共有」を押すと、**写真と栄養を1枚のカードにまとめた画像**を作り、
端末の共有メニューから X・Instagram・LINE などへ渡せます。
写真を撮って記録した直後にも、画面下の「共有」から1手で開けます。

- **カードは端末の中で作られ、開発者のサーバーには送信されません。**
  このアプリは投稿を預からないので、共有しても記録は端末の外に出ません
- 栄養の内訳(たんぱく質・脂質・炭水化物)を載せるかどうかは、共有のたびに選べます
- いいねやコメントは、渡した先のアプリでやり取りされます
- 共有に対応していないパソコンのブラウザでは、カードが画像として保存されます

## データの持ち出し(機種変更・バックアップ)

設定タブの「データを書き出す」で、記録・体重・よく食べるもの・プロフィールをまとめた
JSONファイルを保存できます。新しい端末で「データを読み込む」を選ぶと復元されます。

- **APIキーは書き出しに含まれません。** 新しい端末では登録し直してください。
- 読み込みは上書きではなく**統合**です。同じ記録は重複しません。

## APIキーの扱いについて

APIキーはこの端末のブラウザ内(localStorage)にのみ保存されます。ただし
「ブラウザから直接APIキーを使う」方式は、そのブラウザ環境にアクセスできる人には
キーが見える形になります。共有PCなどでは使用後にキーを削除してください。
キーが漏れた場合は、発行元のコンソールからそのキーを失効させてください。

## ファイル構成

- `index.html` — アプリ本体(画面構造)
- `style.css` — デザイン
- `nutrition.js` — 食事摂取基準の表と、1日の必要栄養量の計算
- `exif.js` — 撮影情報の読み取りと、写る範囲の実寸の計算
- `storage.js` — 記録・体重・よく食べるものの保存(localStorage)と日付ヘルパー
- `charts.js` — グラフの描画(外部ライブラリなしのインラインSVG)
- `api.js` — 各AIサービスへの写真解析リクエスト(プロバイダ定義もここ)
- `share.js` — 共有カードの描画と、端末の共有メニューへの受け渡し
- `app.js` — 画面の描画とイベント処理
- `icons.js` — SVGアイコン(絵文字は使わず線画で統一)
- `manifest.json` / `sw.js` / `icon-*.png` — PWA(ホーム画面追加・オフライン対応)用
- `dev/` — 開発用。ローカルサーバー、静的チェック、ヘッドレスの操作テスト

## 開発する

**ビルドも `npm install` も要りません。**

```bash
npm start   # http://127.0.0.1:8080 で開く
npm test    # 静的チェック + ヘッドレスで90項目以上の操作テスト
```

環境の作り方、テストの足し方、踏んだ罠は **`SETUP.md`** にまとめてあります。

## 注意事項

本アプリが表示する1日の必要栄養量やAIによる栄養推定値は、一般的な目安・参考情報であり、
医学的なアドバイスではありません。妊娠・授乳中の方、成長期のお子様、持病のある方などは、
医師や管理栄養士にご相談のうえご利用ください。18歳以上の方を対象としています。
